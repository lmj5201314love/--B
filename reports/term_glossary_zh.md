# 项目英文术语中英对照表

| 英文术语 | 中文翻译 | 在本项目中的意思 | 简单例子 |
| --- | --- | --- | --- |
| Data Quality Report | 数据质量报告 | 检查数据是否完整、有没有缺失和异常 | `reports/data_quality_report.md` |
| missing value | 缺失值 | 某个单元格没有数据 | PMI 综合指数早期月份为空 |
| anomaly / outlier | 异常值 | 明显偏离一般范围的数据 | 某月进口均价异常偏高 |
| IQR outlier | 四分位距异常值 | 用四分位距方法识别出的异常 | 调价幅度超过正常波动范围 |
| numeric summary | 数值统计摘要 | 对数值列做均值、最大值等统计 | 油价平均值、最大值、最小值 |
| mean | 平均值 | 所有数值加总后除以个数 | 平均上调幅度 |
| median | 中位数 | 排序后位于中间的数 | 传递比例中位数 |
| standard deviation | 标准差 | 衡量波动大小 | 调价动作标准差越大，波动越大 |
| min / max | 最小值/最大值 | 数据中的最低值和最高值 | 最大上调幅度 1137.5 元/吨 |
| mechanism baseline | 机制基线模型 | 最简单的机制复现模型 | 用油价变化线性解释调价幅度 |
| theory adjustment | 理论调价 | 模型认为应该调多少 | `theory_adjust_rule_cny_per_ton` |
| actual adjustment | 实际调价 | 历史公告中真实调价幅度 | `avg_adjust_cny_per_ton` |
| pass-through ratio | 价格传递比例 | 实际调价除以理论调价 | 比例为 0.8 表示传导 80% |
| pass-through gap | 传递缺口 | 理论调价减实际调价 | 理论 300、实际 200，缺口 100 |
| under-transmitted | 不足传递 | 实际调价绝对值小于理论调价 | 应上调 300，实际上调 200 |
| over-transmitted | 过度传递 | 实际调价绝对值大于理论调价 | 应下调 200，实际下调 300 |
| oil price regime | 油价区间 | 按油价水平分组 | 低油价、正常油价、高油价 |
| welfare loss | 福利损失 | 用一个数衡量策略带来的综合损失 | 消费者、炼厂、CPI 等损失加权 |
| consumer loss | 消费者损失 | 油价上调给消费者带来的压力 | 上调越大，消费者损失越大 |
| refinery loss | 炼厂损失 | 实际调价偏离理论成本调价造成的炼厂压力 | 理论应上调但没上调 |
| CPI loss | CPI 损失 | 油价上调对通胀的冲击 | CPI 高时上调损失更大 |
| volatility loss | 波动损失 | 调价动作变化过大带来的预期冲击 | 本期上调 500、下期下调 400 |
| security loss | 能源安全损失 | 长期成本未传导可能带来的供应压力 | 累计未传导缺口很大 |
| sensitivity analysis | 敏感性分析 | 改变权重看结论是否变 | 民生优先、炼厂优先等权重情景 |
| robustness check | 稳健性检验 | 换方法或变量验证结论是否稳定 | 换油价代理后 S5 仍优于 S0 |
| policy constraint | 政策约束 | 政策上不能只追求数学最优，还要可执行 | CPI 高时限制大幅上调 |
| policy band | 政策区间 | 根据油价水平设置不同规则 | 40/80/130 美元区间 |
| floor price | 地板价 | 油价太低时不再继续下调的规则 | 40 美元以下不继续下调 |
| ceiling price | 最高限价/天花板价 | 国内成品油最高零售限价，或高油价上限约束 | 北京汽油最高限价 |
| carry / accumulated adjustment | 搁浅累计项 | 没达到调价门槛的理论调价累计到以后 | 本期 30 元不调，下期继续累计 |

## 使用提示

- CSV 字段名不要翻译成中文，否则脚本会找不到字段。
- 论文正文可以使用中文术语，但首次出现时最好括号注明英文或字段名。
- “福利损失”不是现实中直接观测的数据，而是我们为了比较策略建立的评价函数。
