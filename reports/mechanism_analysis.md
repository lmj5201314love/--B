# 机制复现增强版与价格传递不对称分析

## 1. 本阶段完成内容

本阶段围绕“任务一：机制理解与历史数据验证”展开，没有进入动态优化、社会福利损失函数、强化学习或动态规划。主要完成：

- 建立统一符号表 `reports/symbol_table.md`；
- 基于 2016-01-01 至 2026-05-09 主样本，使用上一阶段最优主代理变量复现理论调价；
- 在简单线性理论调价基础上加入 50 元/吨调价门槛和累计搁浅规则；
- 输出机制复现增强版主表 `data/processed/modeling_dataset_mechanism.csv`；
- 计算 raw 线性模型与 rule 门槛累计模型的复现评价；
- 计算价格传递比例、传递缺口和分组不对称统计；
- 输出理论/实际对比、传递比例分布、油价区间传递缺口等 SVG 图表。

## 2. 为什么使用 Brent-WTI 加权油价作为主代理

上一阶段 `outputs/tables/mechanism_baseline_comparison.csv` 显示，`brent_wti_weighted_window_change` 的 RMSE 最低，为 `109.85`，方向准确率为 `75.38%`。虽然 `brent_wti_avg_window_change` 的 MAE 略低，但加权 Brent-WTI 代理在整体误差稳定性上更好。

因此本阶段将 `brent_wti_weighted_window_change` 作为主解释变量 `ΔO_t`，并保留 `brent_wti_avg_window_change` 与 `basket_window_change` 作为后续稳健性对照。

## 3. raw 线性模型与 50 元门槛模型的差异

raw 模型直接使用：

```text
ΔP_raw_t = k * ΔO_t + b
```

其中 `k = 47.719011`，`b = 1.803467`。该模型可以较好解释实际调价窗口的上调/下调方向，但没有“不调价”机制，因此对搁浅窗口的识别能力很弱。

rule 模型在 raw 理论调价基础上加入：

- 50 元/吨调价门槛；
- 未达门槛时累计到 `A_t`；
- 达到门槛后释放累计项并清零。

该规则使理论调价更接近政策机制本身，尤其改善了“不调价窗口”的识别。

## 4. 机制复现准确性

主样本 2016 年以后共 `260` 个调价窗口：

| 模型 | MAE | RMSE | 方向准确率 | 是否调价准确率 | 不调价识别准确率 |
| --- | ---: | ---: | ---: | ---: | ---: |
| raw 线性模型 | 69.14 | 109.85 | 75.38% | 78.08% | 0.00% |
| rule 门槛累计模型 | 68.51 | 111.42 | 83.08% | 83.85% | 64.91% |

结论是：rule 模型的整体 MAE、方向准确率、是否调价准确率和不调价识别明显更好；但 raw 模型在 RMSE 上略低，并且在实际调价窗口内的连续幅度拟合更好。若目标是“复现政策机制”，rule 模型更合适；若只看调价窗口的幅度回归，raw 模型仍有参考价值。

## 5. 是否存在价格传递不对称

存在较明显的不对称迹象，但方向需要分口径解释：

- 按理论方向看，理论上调窗口平均传递比例为 `1.19`，理论下调窗口为 `1.08`；但理论下调窗口的中位数传递比例更高，约 `1.21`，理论上调为 `1.15`。
- 按实际方向看，实际下调窗口平均传递比例为 `1.35`，高于实际上调窗口的 `1.21`；实际下调窗口过度传递率为 `77.03%`，也高于实际上调的 `68.22%`。
- 大幅理论上调窗口平均传递比例为 `0.89`，表现为一定不足传递；大幅理论下调窗口平均传递比例为 `1.03`，更接近充分传递或略超传递。

因此，样本中下调窗口并未表现为“下调滞后”，反而在实际下调口径上表现出更强传递。这可能与高油价时期政策约束、低油价时期地板价约束、搁浅累计项释放有关，后续应做稳健性检验。

## 6. 油价区间表现

按 `brent_wti_weighted_window_avg` 分区：

| 区间 | 样本数 | 平均实际调价 | 平均理论调价 | 平均传递比例 | 不调价比例 | 平均绝对误差 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| low `<40` | 16 | -99.69 | -78.94 | 0.29 | 75.00% | 232.15 |
| normal `40-80` | 187 | 7.15 | 7.30 | 1.31 | 19.25% | 53.05 |
| high `80-130` | 57 | 70.00 | 63.68 | 0.94 | 15.79% | 73.29 |
| extreme_high `>=130` | 0 |  |  |  |  |  |

低油价区间误差最大，平均绝对误差为 `232.15` 元/吨，且不调价比例达到 `75.00%`。这与低油价阶段可能存在政策地板价、税费刚性和特殊时期调控有关。高油价区间平均绝对误差为 `73.29`，高于正常油价区间，但远低于低油价区间。

## 7. 当前模型不足

- 仅使用 Brent-WTI 加权油价变化作为主解释变量，尚未显式加入汇率、成品油消费税、炼化利润和库存周期；
- 50 元门槛与累计规则是简化复现，没有纳入国际油价 40 美元/桶下限、130 美元/桶上限等完整机制；
- `carry` 的累计释放按线性理论值机械执行，未区分公告口径中的暂停、搁浅、特殊调控；
- 价格传递比例在理论调价较小时较敏感，本阶段已限制在 `abs(theory_adjust_rule_cny_per_ton) >= 50` 的窗口计算，但仍需稳健性检验；
- 原油进口月度数据只到 2024-12，后续窗口进口变量缺失；PMI 综合指数早期月份也存在缺失。
